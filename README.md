# Скан PDF (Android)

Превращает фото документов в аккуратный скан-PDF **полностью офлайн**:
в приложении нет разрешения на интернет и нет ни одной сторонней библиотеки.

Что делает с каждым фото (те же параметры, что мы подбирали на ваших документах):
1. Обрезает лист по рамке (авто-поиск + ручная подгонка углов) и выправляет перспективу.
2. Убирает серый фон и тени: бумага становится белой, цвет (синие подписи, штампы) остаётся.
3. Выравнивает текст по горизонту.
4. Собирает все страницы в один PDF формата A4.

Источники: галерея (в том числе HEIC), камера, «Поделиться» из любого приложения.
Результат: `Загрузки/ScanPdf/<имя>.pdf`, дальше можно сразу открыть или отправить.

## Как собрать

**Android Studio:** File -> Open -> папка проекта -> Run (нужен Android SDK 34).

**Из консоли:** `./gradlew assembleDebug`, APK: `app/build/outputs/apk/debug/app-debug.apk`.

**Без Android Studio:** залейте проект в репозиторий на GitHub, Actions соберёт APK
(`.github/workflows/build.yml`), готовый файл будет во вкладке Actions -> Artifacts.

## Устройство

- `ScanProcessor.kt` - вся обработка изображения (перспектива, фон, поворот, поиск листа).
- `PdfWriter.kt` - свой компактный писатель PDF (JPEG внутри, A4).
- `MainActivity.kt` - список страниц, импорт, создание PDF.
- `CropActivity.kt`, `CropView.kt` - экран ручной подгонки углов листа.

minSdk 29 (Android 10+). HEIC открывается средствами системы.
